# Spotter Freight Rate Prediction

Machine Learning Engineer assessment for predicting freight spot rates from historical load data.

The project includes data preparation, feature engineering, model training, evaluation, validation-set prediction, and the December scenario analysis required by the assessment.

## Setup

Create and activate a virtual environment:

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Place the assessment CSV files in:

```text
data/raw/
```

Required files:

```text
train-test.csv
validation.csv
validation-predictions-template.csv
december-chart-inputs.csv
```

The raw assessment data is not included in the repository.

## Running the pipeline

Run the complete pipeline with:

```bash
python run.py
```

The pipeline handles:

1. Loading the data
2. Cleaning and preprocessing
3. Feature engineering
4. Chronological train/holdout split
5. Model training
6. Model evaluation
7. Prediction on the validation dataset
8. December scenario prediction
9. Generation of evaluation outputs

### Optional arguments

Skip Optuna tuning:

```bash
python run.py --skip-tune
```

Specify the number of Optuna trials:

```bash
python run.py --n-trials 50
```

Use an existing trained model:

```bash
python run.py --predict-only
```

## Model

The final model uses an ensemble of:

* LightGBM
* XGBoost

The models were tuned using Optuna and combined using a weighted blend.

The development data is split chronologically, with the most recent period used as the holdout set. This reflects the time-dependent nature of freight rates and avoids using future observations to train the model.

## Evaluation

Results on the chronological holdout set:

| Metric               |   Value |
| -------------------- | ------: |
| RMSE                 | $581.41 |
| MAE                  | $127.22 |
| MAPE                 |   5.28% |
| R²                   |  0.8548 |
| Within 10% of actual |  94.30% |
| Within 20% of actual |  96.68% |

The model performs well on the majority of loads, although errors increase for a small number of high-value loads. This limitation is discussed in the assessment report.

## December scenario

The December scenario uses the fixed load characteristics provided in the assessment:

* Origin: Lexington
* Destination: Fort Wayne
* Distance: 360 miles
* Equipment: Dry Van
* Weight: 32,000 lb

The prediction is generated for each day in December while changing only the date.

The resulting chart is generated using the provided `score.py` script.

## Source code

The main pipeline code is located in `src/`:

| File               | Purpose                                   |
| ------------------ | ----------------------------------------- |
| `preprocessing.py` | Data loading, cleaning, and preprocessing |
| `features.py`      | Feature creation and transformations      |
| `train.py`         | Model training and hyperparameter tuning  |
| `evaluate.py`      | Model evaluation and metrics              |
| `predict.py`       | Validation and scenario predictions       |

`run.py` is the main entry point and connects these steps into a single pipeline.

## Validation

The supplied `score.py` file is used to validate the final predictions and generate the required December chart.

The provided scorer was kept unchanged.
